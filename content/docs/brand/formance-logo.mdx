```tsx

```

<ComponentPreview name="formance-icon-colors" />

`emerald`, `gold` and `cobalt` are dark circles carrying a white pattern; `slate`
and `lilac` are light circles carrying an `emerald-700` one. The circle is one
step of the palette in each case — `emerald-700`, `emerald-200`, `lilac-500`,
`gold-500`, `cobalt-600` — and `slate` names the light emerald pairing, matching
`BadgeEyebrow`'s variant of the same name.

The size prop means the same thing for a tile as for the plain icon: it sets the
outer width, so `size="xl"` is a 64px circle. Inside it the pattern takes 77% of
the width, the proportion the brand art draws — and the plain icon keeps that same
margin with nothing behind it. So a variant can be added or dropped without the
pattern changing size or moving: the circle appears around the mark rather than
under a smaller one, and a row of mixed plain and tiled marks reads as one set.
