Prompt Input is a message field with attachments and a send button.

<ComponentPreview name="prompt-input" peekCode />

The person types into Prompt Input to send a message to the agent. It is an [Input Group](/docs/components/input-group) with a textarea, an attach button, the [Model Selector](/docs/ai-elements/model-selector) menus, and a send button. Attached files show as [Attachment](/docs/ai-elements/attachment) chips above the text.

## Installation

Prompt Input is built with the [Input Group](/docs/components/input-group), [Attachment](/docs/ai-elements/attachment), and [Dropdown Menu](/docs/components/dropdown-menu) components.

```bash
npx shadcn@latest add @formance/input-group @formance/attachment @formance/dropdown-menu
```

## Usage

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupTextarea,
} from '@/components/ui/input-group';
```

```tsx
<form ref={formRef} onSubmit={onSubmit}>
  <InputGroup>
    <InputGroupTextarea
      value={text}
      onChange={(event) => setText(event.target.value)}
      placeholder="Ask the agent to change your schema…"
      className="p-3"
    />
    <InputGroupAddon align="block-end">
      <InputGroupButton
        size="icon-sm"
        variant="outline"
        aria-label="Attach files"
        onClick={() => inputRef.current?.click()}
      >
        <PlusIcon />
      </InputGroupButton>
      <InputGroupButton
        type="submit"
        size="icon-sm"
        variant="primary"
        className="ml-auto"
        disabled={!canSend}
        aria-label="Send"
      >
        <ArrowUpIcon />
      </InputGroupButton>
    </InputGroupAddon>
  </InputGroup>
</form>
```

## Attachments

The attach button opens a hidden file input. Show each file as an [Attachment](/docs/ai-elements/attachment) in an addon with `align="block-start"`. Give each attachment a button to remove it.

## Model and effort

Put the two [Model Selector](/docs/ai-elements/model-selector) menus in the `block-end` addon, between the attach button and the send button. Move `ml-auto` from the send button to the first menu trigger. The two menus then sit next to the send button.

## Keyboard

Enter sends the message. Shift+Enter adds a new line.

```tsx
onKeyDown={(event) => {
  if (event.key === 'Enter' && !event.shiftKey) {
    event.preventDefault();
    formRef.current?.requestSubmit();
  }
}}
```

## AI SDK

Send the text and the `FileList` of the file input.

```tsx
sendMessage({ text, files });
```

The route streams the reply with `result.toUIMessageStreamResponse()`.
