AI Elements are the parts of a chat or agent interface. They are the shadcn AI components and patterns with Formance styling. The props and exports are the same as upstream, so the shadcn documentation applies to them too.

They follow the [AI SDK](https://ai-sdk.dev) message model, but the components do not depend on it. The demos script their conversations with `@shadcn/helpers`, so they run without a model or an API key.

## Components

These are in the [Components](/docs/components/introduction) section. Install them from the registry, for example `npx shadcn@latest add @formance/trace`.

- [Message Scroller](/docs/components/message-scroller) holds the conversation and keeps the latest turn in view.
- [Message](/docs/components/message) is one row, with an avatar, a header, and a footer.
- [Bubble](/docs/components/bubble) is the surface of the text in a message.
- [Marker](/docs/components/marker) shows a status between messages: thinking, an applied edit, or a date.
- [Attachment](/docs/components/attachment) shows a file that the user or the agent adds to the conversation.
- [Trace](/docs/components/trace) is a list of agent steps. Most patterns are built on it.
- [Code Block](/docs/components/code-block) shows code, terminal output, and diffs, with the Formance code theme.
- [Questionnaire](/docs/components/questionnaire) asks the user a sequence of questions, for example to clarify a request.

## Patterns

A pattern is a composition of the components above. There is nothing more to install: copy the code of the demo into your project.

- **The thread:** [Chat](/docs/ai-elements/chat), [Message](/docs/ai-elements/message), [Prompt Input](/docs/ai-elements/prompt-input), [Suggestion](/docs/ai-elements/suggestion), [Model Selector](/docs/ai-elements/model-selector), [Context](/docs/ai-elements/context), [Checkpoint](/docs/ai-elements/checkpoint).
- **The steps of the agent:** [Reasoning](/docs/ai-elements/reasoning), [Chain of Thought](/docs/ai-elements/chain-of-thought), [Plan](/docs/ai-elements/plan), [Task](/docs/ai-elements/task), [Queue](/docs/ai-elements/queue), [Subagent](/docs/ai-elements/subagent).
- **Tools and their output:** [Tool](/docs/ai-elements/tool), [Confirmation](/docs/ai-elements/confirmation), [Terminal](/docs/ai-elements/terminal), [Stack Trace](/docs/ai-elements/stack-trace), [Test Results](/docs/ai-elements/test-results), [File Tree](/docs/ai-elements/file-tree).
- **Sources:** [Sources](/docs/ai-elements/sources), [Inline Citation](/docs/ai-elements/inline-citation).
