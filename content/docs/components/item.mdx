## Usage

```tsx
import {
  Item,
  ItemContent,
  ItemDescription,
  ItemGroup,
  ItemMedia,
  ItemSeparator,
  ItemTitle,
} from '@/components/ui/item'
```

```tsx
<ItemGroup>
  <Item>
    <ItemMedia variant="icon">
      <WalletIcon />
    </ItemMedia>
    <ItemContent>
      <ItemTitle>Main Wallet</ItemTitle>
      <ItemDescription>Primary wallet for transactions</ItemDescription>
    </ItemContent>
  </Item>
</ItemGroup>
```

`ItemDescription` shows two lines at most. To show the full text, add `className="line-clamp-none"`.

## API reference

### Item

| Prop        | Type                                 | Default     | Description                                                                                                             |
| ----------- | ------------------------------------ | ----------- | ----------------------------------------------------------------------------------------------------------------------- |
| `variant`   | `"default" \| "outline" \| "muted"`  | `"default"` | The visual treatment.                                                                                                   |
| `size`      | `"default" \| "sm"`                  | `"default"` | The padding and the gap.                                                                                                |
| `asChild`   | `boolean`                            | `false`     | Render the child, for example an `a` or a `button`. An `a` or a `button` shows a hover style.                           |
| `className` | `string`                             | -           | More classes for the item.                                                                                              |

An item with `aria-current` (any value except `false`) or `aria-selected="true"` shows the selected style.
