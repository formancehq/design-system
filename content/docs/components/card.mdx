## Usage

```tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from '@/components/ui/card'
```

```tsx
<Card>
  <CardHeader>
    <CardTitle>Transaction Summary</CardTitle>
    <CardDescription>Overview of recent payment activity</CardDescription>
  </CardHeader>
  <CardContent>
    <p>Total processed: 1,024 transactions</p>
  </CardContent>
  <CardFooter>
    <p className="text-sm text-muted-foreground">Last updated 5 minutes ago</p>
  </CardFooter>
</Card>
```

## Heading level

`CardTitle` renders a `div`, because the card does not know the heading level of the page. When the title is a heading, use `asChild` and give it the level of the page.

```tsx
<CardTitle asChild>
  <h2>Transaction Summary</h2>
</CardTitle>
```

The title keeps its classes and its `data-slot`. Typeset heading styles do not apply to it.

## API reference

### Card

| Prop         | Type      | Default | Description                                 |
| ------------ | --------- | ------- | ------------------------------------------- |
| `variant`    | `"muted"` | -       | The visual treatment.                       |
| `isDisabled` | `boolean` | `false` | Fades and blurs the card, and blocks input. |
| `className`  | `string`  | -       | More classes for the card.                  |

### CardTitle

| Prop        | Type      | Default | Description                                     |
| ----------- | --------- | ------- | ----------------------------------------------- |
| `asChild`   | `boolean` | `false` | Render the child, for example an `h2` or `h4`. |
| `className` | `string`  | -       | More classes for the title.                     |
