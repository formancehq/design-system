## Usage

```tsx
import { Marker, MarkerContent, MarkerIcon } from '@/components/ui/marker';
```

```tsx
<Marker role="status">
  <MarkerContent className="shimmer">Thinking…</MarkerContent>
</Marker>
```

Add the `shimmer` utility to `MarkerContent` while a step is pending, and set
`role="status"` so that screen readers announce it.
