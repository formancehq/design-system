## Usage

```tsx
import { Marker, MarkerContent, MarkerIcon } from '@/components/ui/marker';
```

```tsx
<Marker role="status">
  <MarkerContent className="shimmer">Thinking…</MarkerContent>
</Marker>
```

Add the `shimmer` utility to `MarkerContent` while a step is pending, and set
`role="status"` so that screen readers announce it.

## Composition

```text
Marker
├── MarkerIcon
└── MarkerContent
```

## Features

- Three variants: an inline marker, a row with a border, and a separator with a label.
- A decorative icon slot that assistive tech does not read.
- `asChild` on `Marker` makes a link marker or a button marker.
- Works with the `shimmer` utility for streaming status text.
- Each part accepts `className`.

## Accessibility

- For a marker that streams or shows progress, for example "Thinking…", set
  `role="status"`. `Marker` sends `role` to its element.
- A separator with a label needs no role. Its lines are decorative, and screen
  readers read its text. Do not add `role="separator"` to it: a separator takes
  its name from `aria-label`, not from its text.
- The border of a `border` marker is decorative. Choose the role from the
  purpose of the marker.
- `MarkerIcon` has `aria-hidden`, so `MarkerContent` gives the meaning. For a
  marker with only an icon, add an `aria-label`.
- When a marker is interactive, use a real `<button>` or `<a>` with `asChild`.
  The text of the marker is the accessible name.

## API reference

### Marker

| Prop        | Type                                   | Default     | Description                           |
| ----------- | -------------------------------------- | ----------- | ------------------------------------- |
| `variant`   | `"default" \| "separator" \| "border"` | `"default"` | The visual treatment.                 |
| `asChild`   | `boolean`                              | `false`     | Render the child, for example a link. |
| `className` | `string`                               | -           | More classes for the marker.          |

### MarkerIcon

| Prop        | Type     | Default | Description                     |
| ----------- | -------- | ------- | ------------------------------- |
| `className` | `string` | -       | More classes for the icon slot. |

### MarkerContent

| Prop        | Type     | Default | Description                   |
| ----------- | -------- | ------- | ----------------------------- |
| `className` | `string` | -       | More classes for the content. |
