## Usage

```tsx
import { Bubble, BubbleContent, BubbleReactions } from '@/components/ui/bubble';
```

```tsx
<Bubble variant="muted">
  <BubbleContent>How do withdrawals move money?</BubbleContent>
  <BubbleReactions role="img" aria-label="Reaction: thumbs up">
    <span>👍</span>
  </BubbleReactions>
</Bubble>
```

Use `muted` for the messages of the user, and `ghost` for long assistant
replies rendered with the [Markdown](/docs/fragments/markdown) fragment.

## Composition

```text
Bubble
├── BubbleContent
└── BubbleReactions
```

Use `BubbleGroup` to group consecutive bubbles from the same sender:

```text
BubbleGroup
├── Bubble
│   └── BubbleContent
└── Bubble
    └── BubbleContent
```

## Features

- Seven variants, from a strong primary bubble to content with no frame.
- Start and end alignment, for the user and for the assistant.
- Reactions that attach to the edge of the bubble, with a side and an alignment.
- A bubble is as wide as its content, to a maximum of 80% of the container.
- `asChild` on `BubbleContent` makes a link bubble or a button bubble.
- Each part accepts `className`.

## Examples

### Variants

Use `variant` to change the visual treatment of the bubble.

<ComponentPreview name="bubble-variants" />

### Sizes

A bubble grows with its content: one line, a wrapped paragraph, or several paragraphs.

<ComponentPreview name="bubble-sizes" />

| Variant       | Description                                      |
| ------------- | ------------------------------------------------ |
| `default`     | A strong primary bubble, usually for the user.   |
| `secondary`   | A neutral bubble for conversation content.       |
| `muted`       | A bubble with less emphasis, for quiet content.  |
| `tinted`      | A bubble with a light tint of the primary color. |
| `outline`     | A bubble with a border, for secondary content.   |
| `ghost`       | Content with no frame, for assistant text.       |
| `destructive` | A bubble for errors and failed actions.          |

The `ghost` variant has no maximum width, so assistant text can use the full
row.

### Alignment

Use `align` on `Bubble` to align the bubble to the start or to the end of the
conversation.

<ComponentPreview name="bubble-alignment" />

| align   | Description                                        |
| ------- | -------------------------------------------------- |
| `start` | Align the bubble to the start of the conversation. |
| `end`   | Align the bubble to the end of the conversation.   |

In a chat interface, set `align` on the [Message](/docs/components/message)
instead. The bubbles in the message then align with it.

### Bubble group

Use `BubbleGroup` to group consecutive bubbles from the same sender. Set
`align` on each `Bubble`, not on the `BubbleGroup`.

<ComponentPreview name="bubble-group" />

### Links and buttons

Set `asChild` on `BubbleContent` to render a bubble as a link or as a button.

<ComponentPreview name="bubble-link-button" />

```tsx
<Bubble variant="muted">
  <BubbleContent asChild>
    <button type="button">Explain my chart of accounts</button>
  </BubbleContent>
</Bubble>
```

### Reactions

Use `BubbleReactions` to show reactions or quick actions. Use `side` and
`align` to set the position. `side="top"` attaches the row to the top edge.
Reactions go across the edge of the bubble, so keep a large `gap` between
rows.

## Accessibility

- Reactions are a row of emoji. A screen reader reads each glyph with no
  context, and reads `+2` as "plus two". Set `role="img"` and an `aria-label`
  on `BubbleReactions`, so the row is announced one time.
- When a reaction is interactive, use a button. Give an `aria-label` to a
  button that has only an icon.
- When a bubble is interactive, use a real `<button>` or `<a>` with `asChild`.
  `BubbleContent` shows a focus ring, and the text of the bubble is the
  accessible name.
- A variant gives meaning with color. Also give the meaning in the text, the
  alignment, or an icon. For a `destructive` bubble, put the error in the text.

## API reference

### Bubble

| Prop        | Type                                                                                       | Default     | Description                   |
| ----------- | ------------------------------------------------------------------------------------------ | ----------- | ----------------------------- |
| `variant`   | `"default" \| "secondary" \| "muted" \| "tinted" \| "outline" \| "ghost" \| "destructive"` | `"default"` | The visual treatment.         |
| `align`     | `"start" \| "end"`                                                                         | `"start"`   | The side of the conversation. |
| `className` | `string`                                                                                   | -           | More classes for the bubble.  |

### BubbleContent

| Prop        | Type      | Default | Description                                       |
| ----------- | --------- | ------- | ------------------------------------------------- |
| `asChild`   | `boolean` | `false` | Render the child, for example a button or a link. |
| `className` | `string`  | -       | More classes for the content.                     |

### BubbleReactions

| Prop        | Type                | Default    | Description                            |
| ----------- | ------------------- | ---------- | -------------------------------------- |
| `side`      | `"top" \| "bottom"` | `"bottom"` | The edge of the bubble.                |
| `align`     | `"start" \| "end"`  | `"end"`    | The position along the edge.           |
| `className` | `string`            | -          | More classes for the row of reactions. |

### BubbleGroup

| Prop        | Type     | Default | Description                 |
| ----------- | -------- | ------- | --------------------------- |
| `className` | `string` | -       | More classes for the group. |
