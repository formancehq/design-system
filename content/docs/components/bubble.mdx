## Usage

```tsx
import { Bubble, BubbleContent } from '@/components/ui/bubble';
```

```tsx
<Bubble variant="muted">
  <BubbleContent>How do withdrawals move money?</BubbleContent>
</Bubble>
```

Use `muted` for the messages of the user, and `ghost` for long assistant
replies rendered with the [Markdown](/docs/fragments/markdown) fragment.
