## Usage

```tsx
import {
  Message,
  MessageAvatar,
  MessageContent,
  MessageFooter,
  MessageHeader,
} from '@/components/ui/message';
```

```tsx
<Message>
  <MessageAvatar>
    <FormanceIcon variant="emerald" size="md" />
  </MessageAvatar>
  <MessageContent>
    <MessageHeader>Schema assistant</MessageHeader>
    <Bubble>
      <BubbleContent>Deposits land in bank:omnibus.</BubbleContent>
    </Bubble>
    <MessageFooter>Answered from the current schema</MessageFooter>
  </MessageContent>
</Message>
```

Set `align="end"` on the messages of the current user.

## Examples

### Group

Wrap consecutive messages in `MessageGroup`, and consecutive bubbles of one
sender in `BubbleGroup`.

<ComponentPreview name="message-group" />

### Avatar

Put an `Avatar` in `MessageAvatar`. The avatar aligns to the last line of the message.

<ComponentPreview name="message-avatar" />

### Header and footer

Use `MessageHeader` for the name of the sender, and `MessageFooter` for a status such as the read time.

<ComponentPreview name="message-header-footer" />

### Actions

Put icon buttons in `MessageFooter`. Show an error and a retry button when a message does not send.

<ComponentPreview name="message-actions" />
