## Best practices

- Use the same variants as [Badge Status](/docs/components/badge-status): `valid`, `destructive`, `info`, `warning`, `zinc` (default) and `outline`. Use the dot where a badge takes too much space, for example in a table cell or a list row.
- The dot is static. Do not add a spinner next to it.
- Give the status as text next to the dot: the colour must not be the only signal. Do not add text such as `Status: Active`: the label gives the status.
- When the dot has no text, give it a name: `<StatusDot variant="valid" role="img" aria-label="Active" />`.
