## API reference

### Tabs

| Prop          | Type                         | Default        | Description                            |
| ------------- | ---------------------------- | -------------- | -------------------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | The direction of the triggers.         |
| `...props`    | `TabsPrimitive.Root` props   | -              | Props given to the Radix `Tabs.Root`.  |

### TabsList

| Prop       | Type                       | Default     | Description                                                                                         |
| ---------- | -------------------------- | ----------- | --------------------------------------------------------------------------------------------------- |
| `variant`  | `"default" \| "line"`      | `"default"` | The visual treatment.                                                                               |
| `scroll`   | `boolean`                  | `false`     | Horizontal orientation only. The list is never wider than its container and scrolls when its triggers do not fit. |
| `...props` | `TabsPrimitive.List` props | -           | Props given to the Radix `Tabs.List`.                                                               |

### TabsTrigger

| Prop            | Type                          | Default | Description                                                        |
| --------------- | ----------------------------- | ------- | ------------------------------------------------------------------ |
| `value`         | `string`                      | -       | Required. The value of the tab that the trigger opens.             |
| `caseSensitive` | `boolean`                     | `false` | Keep the case of the label. By default, the label is in uppercase. |
| `...props`      | `TabsPrimitive.Trigger` props | -       | Props given to the Radix `Tabs.Trigger`.                           |
