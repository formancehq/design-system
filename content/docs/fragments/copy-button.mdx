An outline icon button that writes `text` to the clipboard and confirms with a check for 1.5s before reverting. The text is trimmed on copy, and the click is stopped from propagating so the button is safe inside a clickable row or card header.

Pass `text` alone for an icon-only button. Pass `label` to render a wider button with a caption that swaps to "Copied" while confirming. This is the copy affordance used by `ApiSnippet` and `LedgerSchema`, so copy and play actions read consistently across fragments.
