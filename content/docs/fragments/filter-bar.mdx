The [Filter Builder](/docs/fragments/filter-builder)'s tree, drawn inline so it stays on screen above a table. It holds the same `TFilterGroup` and writes the same ledger query, so the two can edit one value side by side.

- A **condition** is one chip of segments: the field, the operator, the value, and remove.
- A **group** is a framed run of chips. Its **+** adds a condition or, while `maxDepth` allows, a nested group.
- The **join** sits between each two children of a group. A group has one join, so a click on any of them switches the whole group between `and` and `or`.
- A group that loses its last chip is removed with it.

## Usage

```tsx
import { FilterBar } from '@/components/ui-fragments/filter-builder/filter-bar';
import {
  createFilterGroup,
  queryOfFilter,
} from '@/components/ui-fragments/filter-builder/filter-query';
```

```tsx
const [filter, setFilter] = useState(() => createFilterGroup());

<FilterBar fields={fields} value={filter} onChange={setFilter} />;
```

`maxDepth={1}` hides groups: a flat row of chips with one join. `actions` takes the toolbar's other controls, drawn after Clear in the same row, such as the Console's Raw body query.
