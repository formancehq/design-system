A client-side table on TanStack Table v9: sort, search, faceted filters, column visibility, pinning, resizing, expandable rows and pagination. Each part lives in its own file under `components/ui-fragments/data-table/`, so a custom table can reuse the toolbar and the content with its own `useTable`.

## Usage

Import each part from its own file:

```tsx
import { DataTable } from '@/components/ui-fragments/data-table/data-table';
import { DataTableColumnHeader } from '@/components/ui-fragments/data-table/data-table-column-header';
import type { ColumnDef } from '@/components/ui-fragments/data-table/data-table-features';
import { DataTableRowActions } from '@/components/ui-fragments/data-table/data-table-row-actions';
import { DataTableSkeleton } from '@/components/ui-fragments/data-table/data-table-skeleton';
```

```tsx
<DataTable
  columns={columns}
  data={data}
  initialState={{ sorting: [{ id: 'amount', desc: true }] }}
  searchConfig={[{ placeholder: 'Filter emails...', columnKey: 'email' }]}
/>
```

## Table options

`tableOptions` passes any other TanStack option to `useTable`. Row selection is on and cell selection is off by default; turn either one around, control a state slice, or listen to a change:

```tsx
<DataTable
  columns={columns}
  data={data}
  tableOptions={{
    enableRowSelection: (row) => row.original.status !== 'locked',
    onRowSelectionChange: setRowSelection,
    state: { rowSelection },
  }}
/>
```

The table keeps `features`, `data` and `columns`, and takes `initialState`, `getRowId`, `getRowCanExpand`, `autoResetPageIndex` and `autoResetExpanded` from their own props.

## Build your own table

`DataTable` is `useTable` with `dataTableFeatures`, then `DataTableToolbar`, `DataTableContent` and `DataTablePagination`. To change one part (a server-side pager, say), build the table yourself with the same feature set, so your `ColumnDef` types stay the same:

```tsx
const table = useTable({ features: dataTableFeatures, data, columns });

return (
  <div className="space-y-4">
    <DataTableToolbar table={table} searchConfig={searchConfig} />
    <DataTableContent table={table} />
    <MyPager table={table} />
  </div>
);
```
