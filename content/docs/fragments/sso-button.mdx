## Usage

```tsx
import {
  SsoButton,
  SsoButtonGroup,
  type TSsoProvider,
} from '@/components/ui-fragments/sso-button';
```

```tsx
<SsoButtonGroup onProviderSelect={(provider) => signIn(provider)} />
```

The brand marks are inline SVG, so the component installs with no icon
dependency of its own. GitHub draws in `currentColor` and follows the theme;
Google and Microsoft keep their brand colours, which stay legible on both the
light and the dark surface.

`SsoButton` forwards every `Button` prop, so `variant`, `size`, `loading` and
`disabled` behave as they do anywhere else.
